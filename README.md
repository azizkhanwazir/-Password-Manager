# 🔐 Password Manager

A simple Password Manager application built using **Python** and **Tkinter**. It allows users to generate random passwords and save website login details through a graphical user interface.

## Features

- Generate random passwords.
- Include uppercase and lowercase letters.
- Include numbers and special characters.
- Save website, email, and password details.
- Confirmation before saving passwords.
- Clear and user-friendly graphical interface.
- Custom colors and buttons.

## Technologies Used

- Python
- Tkinter
- Random Module

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/azizkhanwazir/-Password-Manager.git
   ```

2. Open the project folder.
3. Make sure Python is installed.
4. Run the application:

   ```bash
   python main.py
   ```
